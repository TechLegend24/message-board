# message-board
A small e-ink message board

I made this message board using a Waveshare 1.54inch e-Paper display and an ESP32-C3 SuperMini board.
It is programmed in CircuitPython, and messages are sent to it over Bluetooth UART

Prequesites
  a CircuitPython board capable of Bluetooth and SPI
  a Waveshare 1.54in e-Paper display
  a computer with an editor such as Thonny
  a smart device, such as a phone or tablet, to send UART messages
  a lot of patience and time
